# FoosRank UI/UX Redesign — "Catppuccin Design System"

## Goal

Replace the POC "default Tailwind starter" UI with a cohesive design system built on **Catppuccin Latte (light) + Mocha (dark)**, **mauve/lavender** brand accents, **Space Grotesk + Inter** typography, **lucide-react** icons, and **CSS-only motion**. Includes UX restructuring plus three feature additions: a **real Elo engine**, **player profile pages**, and **head-to-head stats**.

Decisions locked with user: dual theme (system default + toggle) · reskin + new features · mauve/lavender accent · CSS-only animations (no motion library).

---

## 1. Design System Foundation

### 1.1 Theme tokens — rewrite `apps/web/src/styles.css`

Tailwind v4 CSS-first config (no JS config needed). Pattern: semantic CSS vars declared per theme, exposed to Tailwind via `@theme inline` so utilities flip automatically.

```css
@import 'tailwindcss';
@custom-variant dark (&:where(.dark, .dark *));

:root { /* Catppuccin Latte */
  --bg: #eff1f5; --card: #ffffff; --border: #dce0e8;
  --surface: #e6e9ef; --surface-2: #ccd0da;
  --text: #4c4f69; --muted: #6c6f85; --faint: #9ca0b0;
  --brand: #8839ef; --on-brand: #ffffff; --accent: #7287fd; --focus: #7287fd;
  --team-red: #d20f39; --team-blue: #1e66f5;
  --success: #40a02b; --warning: #df8e1d; --live: #fe640b; --danger: #d20f39;
  --gold: #df8e1d; --silver: #9ca0b0; --bronze: #fe640b;
}
.dark { /* Catppuccin Mocha */
  --bg: #1e1e2e; --card: #181825; --border: #313244;
  --surface: #313244; --surface-2: #45475a;
  --text: #cdd6f4; --muted: #a6adc8; --faint: #6c7086;
  --brand: #cba6f7; --on-brand: #11111b; --accent: #b4befe; --focus: #b4befe;
  --team-red: #f38ba8; --team-blue: #89b4fa;
  --success: #a6e3a1; --warning: #f9e2af; --live: #fab387; --danger: #f38ba8;
  --gold: #f9e2af; --silver: #a6adc8; --bronze: #fab387;
}
@theme inline {
  --color-*: var(--*) for every token above   /* enables bg-bg, bg-card, text-muted, bg-brand, text-team-red, etc. */
  --color-brand-soft / --color-team-red-soft / --color-team-blue-soft: derived via color-mix(in srgb, <color> 12%, var(--card))
  --font-display: 'Space Grotesk', ui-sans-serif, system-ui, sans-serif;
  --font-sans: 'Inter', ui-sans-serif, system-ui, sans-serif;
  --animate-fade-up / --animate-fade-in / --animate-scale-in / --animate-pulse-dot + matching @keyframes
}
```

Also in styles.css: base body styles (bg/text/font-sans, antialiasing), `:focus-visible` ring using `--focus`, `::selection` in brand-soft, themed scrollbar, and a `@media (prefers-reduced-motion: reduce)` block disabling all animations/transitions.

**Domain color semantics (kept + refined):** red/blue = team identity (soft tinted panels) · peach `--live` = in-progress matches (replaces amber) · green = wins/positive deltas · red = losses/negative deltas · gold/silver/bronze = podium ranks.

### 1.2 Typography

- Load **Space Grotesk 500/700** (display: headings, logo, scores, Elo numbers) and **Inter 400/500/600** (body) via Google Fonts `<link>` + `preconnect` in `__root.tsx` `head()`.
- `font-display` for h1/logo/stat numerals; `tabular-nums` kept for all stats.
- Section labels pattern: `text-xs font-semibold uppercase tracking-wider text-muted`.

### 1.3 Theme switching

- `src/lib/theme.ts`: `useTheme()` hook — reads `localStorage('foosrank-theme')` → falls back to `prefers-color-scheme`; toggles `.dark` class on `<html>`; persists choice.
- Inline `<script>` in `__root.tsx` document head applies the class before paint (no flash; SSR is off anyway).
- `ThemeToggle` button (Sun/Moon lucide icons) in the shell.

### 1.4 Motion (CSS-only)

- Route content entrances: `animate-fade-up` on page containers.
- Staggered list entrances: inline `style={{ animationDelay: `${i * 40}ms` }}` (capped) on leaderboard/roster/match rows.
- Live-match badge: `animate-pulse-dot` on a status dot.
- Micro-interactions: card hover lift (`transition` + `-translate-y-0.5` + shadow), button `active:scale-[0.98]`, result score `animate-scale-in`.
- `src/lib/use-count-up.ts`: tiny rAF hook animating big numbers (Elo, stats) — no dependency.
- All disabled under `prefers-reduced-motion`.

### 1.5 New dependencies

`lucide-react` (icons) · `clsx` + `tailwind-merge` (`cn()` helper in `src/lib/cn.ts`). Nothing else.

## 5. Feature Work

### 5.1 Real Elo engine
- Move `calculateEloChanges` from `collections/people.ts` → `src/domain/elo.ts`: team rating = mean member Elo; `E = 1/(1+10^((Rb−Ra)/400))`; `change = round(32 × (actual − E))` per team, split equally; mirrored for loser. Update import in `matches/$matchId.tsx`.
- On completion, also apply deltas to `peopleCollection` (currently stored on match but never applied — all players stuck at 1000).
- Add `onUpdate` + `onDelete` persistence handlers to `peopleCollection` (only `onInsert` exists today) — required for Elo updates + rename/delete.
- Existing localStorage matches keep `eloChanges: null`; treat null as 0 in derived views (no migration needed since stored player Elo was never mutated).

### 5.2 Player profiles — `routes/$organizationId/people/$personId.tsx`
Header (avatar, name, rank badge, Elo count-up, W-L, win %, streak) · **Elo sparkline** (inline SVG polyline, no chart lib) from new `eloHistory(personId, matches)` in `domain/elo.ts` (replay by sequence from 1000) · recent match list · **head-to-head** table vs each opponent (new `headToHead(personId, people, matches)` domain fn — opposing-team meetings only).

### 5.3 People management
Rename (prompt-style inline edit → `peopleCollection.update`) and delete (blocked when participant of any match, to protect history integrity).
